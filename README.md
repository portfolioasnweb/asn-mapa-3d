# Mapa 3D

Card do Home Assistant que mostra a casa em 3D e controla luzes, ar-condicionado, cortinas, TV e som.

**A planta de cada casa é montada e entregue pelo instalador ASN.** Este card sozinho não mostra nada: ele só abre plantas originais, entregues pela ASN.

Instalação e suporte: fale com o seu instalador.
